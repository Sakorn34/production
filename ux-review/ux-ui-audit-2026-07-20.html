สรุป3 เรื่องใหญ่ที่ควรจัดการก่อน

  • บั๊กธีม: theme-v2.css ทับค่าที่ตั้งใน appearance.php — เปลี่ยนสีธีม/พรีเซ็ต navy/teal แล้วไม่มีผลจริง เพราะไฟล์ v2 hardcode สีชมพู-ม่วงและโหลดท้ายสุด (รายละเอียด B1)
  • Sidebar ของ parts ไม่คอมม่อน — เมนูซ่อนสนิท ต้อง hover ขอบจอซ้ายถึงจะ "พลิก" ออกมา ผู้ใช้ใหม่ไม่มีทางรู้ (รายละเอียด B2)
  • งานแปลง emoji → SVG ยังไม่จบ — ระบบมีชุดไอคอนกลางแล้ว (shared/ui_icons.php, 44 ไอคอน) แต่ finishgoogs ยังฝัง emoji ดิบ ~300 จุด โดยเฉพาะ system_doc / ma / settings (รายละเอียด B3)

Part 4Mockup Dashboard รวม + Roadmap

แนวคิด "รวม 2 ระบบไว้หน้าเดียว" ที่เสนอ

  • Sidebar เดียว 3 หมวด — ภาพรวม / ทะเบียนเครื่อง (5 เมนู) / สต็อกอะไหล่ (7 เมนู) / ระบบหลังบ้าน — ทำได้จริงเพราะ SSO แชร์ session กันอยู่แล้ว แค่ลิงก์ข้ามโฟลเดอร์
  • Dashboard รวม — KPI 6 ใบ (เครื่อง 3 + อะไหล่ 2 + ความเคลื่อนไหววันนี้ 1) เห็นครบทุกสถานะ: ใหม่/เช่า/สำรอง/ซ่อม/คงเหลือ/ใกล้หมด + กราฟผลิต + donut + ตารางใกล้หมด + activity feed รวม (ใช้ shared/activity_log_core.php ที่รวม 2 ระบบให้อยู่แล้ว)
  • พรีเมี่ยมโดยคงสีธีม — ชมพู/ม่วงเป็น accent บนพื้นขาว, ตัวเลข tabular-nums ตัวหนา, เงา 2 ระดับ, radius 12/8, badge pill ชุดสีเดียว — เลิก gradient แข่งกันหลายใบ
