# คู่มือผู้ใช้งาน — ระบบทะเบียนเครื่องและซ่อมบำรุง

ระบบนี้ใช้บันทึกและติดตามเครื่องที่ผลิต ตั้งแต่ผลิตเสร็จ ไปจนถึงส่งลูกค้า ซ่อม บำรุงรักษา (MA) และอัปเดตเฟิร์มแวร์/ฮาร์ดแวร์ ตลอดอายุการใช้งานของเครื่อง

## เข้าสู่ระบบ

ระบบนี้**ไม่มีหน้ากรอกรหัสผ่านของตัวเอง** — เมื่อเปิดเว็บ ระบบจะพาไปเข้าสู่ระบบผ่านศูนย์กลาง SSO ของบริษัท (bit-online.net) โดยอัตโนมัติ ถ้ายังไม่เคยล็อกอินที่นั่นจะต้องกรอกข้อมูลผ่านหน้า SSO ก่อน แล้วจะถูกพากลับมาที่ระบบนี้พร้อมสิทธิ์การใช้งาน

ทุกคนที่ผ่าน SSO เข้ามาได้ จะใช้งานฟีเจอร์หลักได้ทั้งหมด (ไม่มีการแบ่งสิทธิ์ผู้ใช้เป็นระดับๆ แบบเดิมแล้ว) ยกเว้นหน้า **"ระบบหลังบ้าน"** (ตั้งค่า/ปรับแต่งหน้าตา) ที่ต้องใส่รหัส PIN เพิ่ม — ดูหัวข้อ [ระบบหลังบ้าน](#ระบบหลังบ้าน-ตั้งค่า)

## หน้าแดชบอร์ด (หน้าแรก)

หน้าแรกของระบบสรุปภาพรวม: จำนวนเครื่องทั้งหมด แยกตามสถานะ กราฟการผลิตรายปี/รายเดือน และสถิติแยกตามรุ่นสินค้า (มีรูปประกอบ)

ทุกตัวเลข/แท่งกราฟ **กดดูรายละเอียดต่อได้** เป็นชั้นๆ เช่น:

1. กดปีในกราฟ → เห็นกราฟรายเดือนของปีนั้น
2. กดเดือน → เห็นการ์ดแยกตามรุ่นสินค้าที่ผลิตเดือนนั้น (มีรูป+จำนวน)
3. กดการ์ดรุ่น → เห็นรายชื่อเครื่องแต่ละเครื่อง
4. กดแถวเครื่อง → เห็น **timeline** ประวัติทั้งหมดของเครื่องนั้น (ผลิต ซ่อม อัปเดต ส่งลูกค้า ฯลฯ)

หน้าต่างที่เปิดขึ้นมาเป็น modal ลอยอยู่บนแดชบอร์ด ไม่ต้องเปลี่ยนหน้า

## จัดการทะเบียนเครื่อง

- **รายการเครื่อง** — ดูเครื่องทั้งหมด ค้นหาแบบพิมพ์แล้วเจอทันที (พิมพ์รหัสเครื่อง/ชื่อรุ่น)
- **หน้าเครื่องเดี่ยว** — เปิดได้จากรายการเครื่อง หรือ**สแกน QR/บาร์โค้ด**ที่ติดบนตัวเครื่องแล้วเปิดตรงมาที่หน้านี้เลย แสดงข้อมูลเครื่อง สถานะ ลูกค้าปัจจุบัน และ timeline ประวัติทั้งหมด
- **เพิ่มเครื่องใหม่** (บันทึกการผลิต) — กรอกรุ่นสินค้า รหัสเครื่อง และฟิลด์เฉพาะของรุ่นนั้น (ระบบจะดึงฟิลด์ที่ต้องกรอกตามรุ่นที่เลือกให้อัตโนมัติ) ต้องมีสิทธิ์ "production" จึงจะเห็นเมนูนี้

## ซ่อมและบำรุงรักษา (MA)

- **ประวัติการซ่อม** — ดูรายการซ่อมทั้งหมดแบบอ่านอย่างเดียว กรองตามลูกค้าหรือค้นหาได้
- **บันทึก MA** — เลือกรุ่นสินค้าก่อน (มีการ์ดรูปให้เลือก) แล้วจึงกรอกแบบฟอร์มบันทึกงาน MA ของเครื่องรุ่นนั้น หน้านี้รวมการจัดการ**เครื่องสำรอง/เครื่องเช่า**ไว้ด้วยแล้ว (เมนู "เครื่องสำรอง" เดิมถูกยกเลิกและย้ายมารวมที่นี่ตั้งแต่ 11 ก.ค. 2569)

## อัปเดตเฟิร์มแวร์ / ฮาร์ดแวร์ (FW/HW)

- เลือกรุ่นสินค้า (การ์ดรูปเหมือนหน้า MA) แล้วดูรายการอัปเดตของรุ่นนั้น ค้นหาตามหมายเลขเครื่องหรือรายละเอียดได้ แก้ไข/ลบรายการที่บันทึกผิดได้
- **นำเข้าประวัติจาก CSV** — สำหรับข้อมูลอัปเดตย้อนหลังจำนวนมาก มีหน้านำเข้าไฟล์ CSV โดยเฉพาะ (คอลัมน์ที่ต้องมี: รหัสเครื่อง, วันที่อัปเดต, ประเภท, ชื่อชิ้นส่วน, ค่าเดิม/ค่าใหม่, รายละเอียด, ผู้บันทึก)

## ลูกค้า

- ดูรายชื่อลูกค้าทั้งหมด เพิ่มลูกค้าใหม่ได้
- หน้ารายลูกค้าเดี่ยว แสดงข้อมูลลูกค้า เครื่องที่อยู่ในความดูแล และประวัติการซ่อมของลูกค้ารายนั้น

## ทะเบียนสินค้า (Stock) และการซิงก์

หน้า **"ทะเบียนสินค้า"** (`share.php`) ใช้ดู/แก้ไข/ลบรายการในทะเบียนสินค้ากลาง ซึ่งเป็นฐานข้อมูลเดียวกับที่ทีมสต็อกอะไหล่ใช้ (ดู [ความสัมพันธ์ระหว่าง 2 ระบบ](../README.md#ความสัมพันธ์ระหว่าง-2-ระบบ)) โดยทั่วไปข้อมูลจะถูกส่งเข้าไปอัตโนมัติทุกครั้งที่บันทึกเครื่องผลิตใหม่ ไม่ต้องทำอะไรเพิ่ม

ถ้าพบว่าข้อมูลในทะเบียนเครื่องกับทะเบียนสินค้าไม่ตรงกัน (เช่น sync ล้มเหลวบางรายการ) ผู้ที่มีสิทธิ์เข้าระบบหลังบ้านสามารถเข้าหน้า **"เทียบข้อมูล/Sync"** (`share_admin.php`) เพื่อดูรายการที่ไม่ตรงกัน สั่ง sync ใหม่เป็นรายตัวหรือทั้งหมด และนำเข้าข้อมูลจากไฟล์ CSV ได้

## สแกน QR / บาร์โค้ด

เปิดกล้องสแกนรหัสที่ติดบนเครื่อง แล้วพาไปยังหน้าเครื่องนั้นโดยตรง — ใช้แทนการค้นหาด้วยมือเมื่อยืนอยู่หน้าเครื่องจริง

## การแจ้งเตือน

ไอคอนกระดิ่งที่แถบด้านบนแสดงรายการแจ้งเตือนล่าสุด (อัปเดตอัตโนมัติเป็นระยะ)

## ระบบหลังบ้าน (ตั้งค่า)

หน้าตั้งค่าและปรับแต่งหน้าตาระบบถูกแยกไว้เป็น "ระบบหลังบ้าน" ต้องปลดล็อกก่อนเข้าใช้ทุกครั้ง (นอกจากผู้ใช้ที่ชื่อ Tom ซึ่งข้ามขั้นตอนนี้ได้อัตโนมัติ):

1. ระบบจะแสดงหน้าใส่รหัส PIN 4 หลัก
2. กรอกรหัสที่ได้รับจากผู้ดูแลระบบ
3. เมื่อผ่านแล้วจะเข้าใช้งานได้จนกว่าจะปิด session

ภายในระบบหลังบ้านมี 2 ส่วนหลัก:

- **ตั้งค่า** (`settings.php`) — จัดการรุ่นสินค้า (เพิ่ม/แก้ไข/กำหนดฟิลด์ที่ต้องกรอกของแต่ละรุ่น) และตั้งค่าระบบอื่นๆ
- **ปรับแต่งหน้าตา** (`appearance.php`) — เปลี่ยนชื่อระบบที่แสดงบนหน้าจอ ข้อความหน้า login สีธีมหลัก (ปุ่ม/แถบเมนู/พื้นหลัง) ตำแหน่งเมนู (ซ้าย/ขวา/บน) อัปโหลดโลโก้และไอคอนแท็บเบราว์เซอร์

> การกระทำที่กระทบข้อมูลส่วนกลาง เช่น สั่ง sync ทะเบียนสินค้าทั้งหมด หรือ import CSV ก็ต้องปลดล็อกระบบหลังบ้านก่อนเช่นกัน แม้จะเข้าถึงหน้านั้นได้จากเมนูปกติ

## หน้าที่ถูกยกเลิก/ย้ายไปแล้ว

หากเจอลิงก์เก่าที่พาไปหน้าต่อไปนี้ ระบบจะ redirect ไปหน้าใหม่ให้อัตโนมัติ:

| หน้าเดิม | ปัจจุบัน |
|---|---|
| จัดการรุ่นสินค้า (`products.php`) | รวมเข้าไปที่ "ตั้งค่า" (`settings.php`) แล้ว |
| เทียบสต็อก (`stock_compare.php`) | รวมเข้าไปที่ "ทะเบียนสินค้า" (`share.php`) แล้ว |
| รายงานการผลิต (`report.php`) | รวมเข้าไปที่หน้าแดชบอร์ดแล้ว |
| เครื่องสำรอง (`spares.php`) | ย้ายไปจัดการที่หน้า "บันทึก MA" แล้ว |
| ผู้ใช้งาน (`users.php`) | ไม่มีระบบผู้ใช้ภายในแล้ว (ใช้ SSO ทั้งหมด) |
