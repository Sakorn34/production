# คู่มือผู้ใช้งาน — ระบบจัดการสต็อกอะไหล่

ระบบนี้ใช้บันทึกการรับเข้า-เบิกออกอะไหล่ในคลัง รองรับการเบิกเป็น "ชุด" (Set) และดูภาพรวมสต็อกผ่านแดชบอร์ด

> วิธีติดตั้งระบบ (XAMPP), การตั้งค่าฐานข้อมูล และโครงสร้างไฟล์ ดูได้ที่ [`parts/README.md`](../../parts/README.md) — เอกสารนี้จะอธิบายเฉพาะ **วิธีใช้งานแต่ละหน้า**

เข้าใช้งานผ่าน URL `/parts` ระบบนี้**ไม่มีหน้าล็อกอิน**แยกต่างหาก และไม่ได้ผูกกับระบบ SSO เหมือนระบบทะเบียนเครื่อง — ผู้ที่เข้าถึง URL ได้ก็ใช้งานได้ทันที

## แดชบอร์ด (หน้าแรก)

สรุปภาพรวมสต็อก: จำนวนอะไหล่คงเหลือทั้งหมด รายการอะไหล่ที่ใกล้หมด (ต้องสั่งเพิ่ม) และความเคลื่อนไหวล่าสุด (รับเข้า/เบิกออก)

## จัดการอะไหล่

หน้า **"อะไหล่"** ใช้เพิ่มรายการอะไหล่ใหม่เข้าระบบ (ระบบสร้างรหัสอะไหล่ให้อัตโนมัติ) และดูจำนวนคงเหลือของแต่ละรายการ กดที่รายการใดรายการหนึ่งเพื่อดู **รายละเอียดอะไหล่** — ประวัติการเบิกออกทั้งหมดของอะไหล่ชิ้นนั้นโดยเฉพาะ

## รับเข้า

บันทึกจำนวนอะไหล่ที่รับเข้าคลัง ระบุอะไหล่ จำนวน และผู้รับ ระบบจะบวกจำนวนเข้าไปในสต็อกคงเหลือทันที

## เบิกออก (เป็น Set)

การเบิกอะไหล่ออกทำผ่าน **"Set"** เท่านั้น (ชุดอะไหล่ที่กำหนดไว้ล่วงหน้าว่ามีอะไหล่อะไรบ้าง อย่างละกี่ชิ้น) ขั้นตอน:

1. เลือก Set ที่ต้องการเบิก
2. ระบุจำนวนชุดที่ต้องการเบิก
3. ระบบตรวจสอบว่าสต็อกของอะไหล่ทุกชิ้นในชุดพอหรือไม่ ก่อนตัดสต็อกจริง
4. เมื่อเบิกสำเร็จ ระบบออกเลขที่เอกสารเบิกให้อัตโนมัติ และบันทึกลงประวัติ

ถ้าอะไหล่ชิ้นใดในชุดมีไม่พอ ระบบจะไม่ตัดสต็อกเลย (กันเบิกได้ไม่ครบชุด)

## จัดการ Set

สร้าง/แก้ไขชุดเบิก — กำหนดว่า Set หนึ่งประกอบด้วยอะไหล่อะไรบ้าง อย่างละกี่ชิ้น ใช้เตรียมชุดไว้ล่วงหน้าก่อนไปเบิกออกจริง

## ประวัติเบิก

ดูรายการเบิกออกทั้งหมด เรียงตามเวลา กดรายการใดรายการหนึ่งเพื่อดูรายละเอียด (อะไหล่แต่ละชิ้นในเอกสารเบิกนั้น จำนวน และผู้เบิก)

รายการที่ขึ้นต้นด้วย `WEBHOOK-` เป็นการตัดสต็อกที่มาจากระบบภายนอกโดยอัตโนมัติ ไม่ได้เบิกผ่านหน้าเว็บนี้ — ดู [Webhook API](../api-reference/parts-webhook-api.md)

## ความสัมพันธ์กับระบบทะเบียนเครื่อง

ระบบนี้**ไม่ได้แชร์ฐานข้อมูลเดียวกัน**กับระบบทะเบียนเครื่องและซ่อมบำรุง (`finishgoogs_ma_update`) เชื่อมกันทางเดียวเท่านั้นผ่าน webhook: เมื่อมีการใช้อะไหล่ในกระบวนการผลิต/ซ่อม ระบบภายนอกจะยิง request มาที่ endpoint `parts/api/webhook-stockout.php` เพื่อตัดสต็อกอะไหล่ให้อัตโนมัติ โดยไม่ต้องเข้ามาเบิกผ่านหน้าเว็บนี้เอง
